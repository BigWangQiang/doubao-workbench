# 工作台 3.0.1

本轮包含失败节点最多自动重试五次、可见画布解析器与下载目录设置，以及字字动画插件连接修复。

字字动画故障由正式包未启动本机插件接口和旧插件缺少自定义数据目录发现共同引起，并非应用版本必须等于 2.6.0。正式版仅启用带令牌的回环插件接口，通用任务控制和调试入口保持关闭。每次创建任务先在线确认会员，重复请求共享授权与创建结果，已有任务查询不重新创建任务。

工作台向当前用户标准数据位置发布兼容发现信息，并在退出时清理本进程记录。插件 2.1.1 读取数据定位文件，检查接口协议 v1，不依赖应用版本号；分发包排除插件配置及用户数据。

工作台左侧新增“字字动画”独立页面，内置图片与视频插件包，支持保存 ZIP、查看三步安装指引、检查本机服务状态和常见问题。连接检测只表示工作台端就绪；字字动画刷新出账号池才表示两端连接完成。保存包由受信主窗口发起，不接收远程下载地址，也不暴露连接令牌。

发布沿用在线更新入口和独立摘要签名。69 项隔离回归、主进程及两个前端构建、渲染层类型检查、安装包门禁、Ed25519 摘要签名与图标核验通过。正式打包程序在空数据目录和隐藏测试桌面启动，旧版及 2.1.1 插件均能发现本机接口并读取账号池；会员拒绝及重复提交由隔离测试覆盖，未提交真实付费生成。

“字字动画”页面已在浏览器验证保存动作、账号入口、过期状态、折叠说明及窄视口滚动，无页面脚本错误。最终包保留独立画布资源；发布门禁新增画布入口和扩展资源检查，防止单独构建渲染层后遗漏画布子目录。

正式更新源已发布 3.0.1，安装包与插件包采用版本文件名，下载页提供插件入口。切换只更新静态文件、更新清单及 Nginx 下载路由，不重启网站生成后端。保留上版元数据、下载配置和网页备份；恢复这些文件可撤回更新入口，已安装用户不会自动降级。

待用户验收：在实际字字动画软件中安装插件 2.1.1，刷新账号池并验证自己的生成流程。工作台连接检查仅表示本机端就绪，不代表字字动画已经加载插件。

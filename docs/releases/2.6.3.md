# Lalor 工作台 2.6.3

本次正式更新合并控件等待、自动确认与豆包窗口 IP 绑定三个已打入本地测试包的改动。更新安装包、自动更新清单与官网下载页；不替换官网应用镜像或重启后端。

## 变化

- 比例、时长和滑杆控件延迟挂载时有界等待，保留发送前回读，不因页面尚未加载就立即失败。
- 豆包明确要求确认后回复“确认生成视频”；Dola 不自动回复。
- 在“代理与窗口绑定”中切换豆包/Dola，绑定或解绑窗口 IP，支持按平台随机分配。每 IP 的 10 窗口总上限跨平台计算。
- 个人代理走所选地址，共享代理沿用原中转；对应会话认证、刷新及产物下载使用同一路由。

## 发布与验收

用户已授权正式构建与发布。构建、安装包门禁、包内文件与图标、线上更新清单和下载路径的检查结果记录在本机发布目录的 release-meta 中。

本次不运行测试套件或全量类型检查；真实生成、代理出口切换和从旧版本安装升级仍待用户实机验收。对应定向用例和验收步骤见三个 handoff 文档：doubao-composite-control-readiness、doubao-auto-confirm-readiness、doubao-window-proxy-binding。

保留 2.6.2 安装包、原快捷方式和线上清单/下载页备份。回滚仅恢复更新清单、下载入口与静态页面，不修改用户账号、任务或代理数据。

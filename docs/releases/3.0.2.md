# 工作台 3.0.2

本轮新增账号池内嵌豆包画布的原视频解析入口，修复仅监听导航造成同页展开画布后按钮不出现的问题。解析按钮随可见画布显示，关闭后清除面板、监听和旧下载授权；普通对话页不占用发送按钮位置。解析与下载复用所选账号会话，继续使用原始视频地址。

本地独立画布的豆包 Seedance 2.0 与 Seedance 2.0 Fast 提供 5、10、15 秒选择，主进程按 15 秒入队并保留会员鉴权、额度与发送前控件回读。Dola 和 Mini 不额外开放 15 秒。

发布使用 Windows x64 安装包、现有官方更新源和独立 Ed25519 更新摘要签名，按用户要求不使用 Windows 代码签名证书。原 3.0.1 安装包和回滚元数据保留。

发布前已通过解析器 29 项定向用例、主进程构建及 Electron 隔离 webview 验收：同 URL 延迟展开、关闭清理、重复进入、刷新恢复、无视频按钮时识别画布、原片解析及旧下载拒绝。真实豆包账号生成与完整桌面人工验收未执行；未触发付费生成。

完整构建、安装包门禁与 SHA512 校验通过。安装包大小 143777422 字节，Ed25519 更新摘要签名有效，正式 EXE 内 7 个图标图像与项目图标一致。空数据目录与隐藏测试桌面启动通过，旧版及 2.1.1 字字动画插件均能发现本机接口并读取空账号池；没有访问真实账号或提交任务。

与线上 3.0.1 对应安装包比较，主进程变更仅为账号画布解析接入、解析器生命周期和视频时长校验，新增两个解析模块；独立画布仅替换两个构建资源。包内构建文件与本次构建一致，所有豆包解析扩展资源与源码一致，未遗漏独立画布资源。

官方更新源、稳定下载入口和下载页已切换 3.0.2。公网完整下载校验通过：安装包大小与 SHA512、摘要签名、blockmap 及原字字动画插件包均匹配；更新清单与稳定入口禁止缓存，版本文件使用不可变缓存。安装包 SHA512：`+QFKOhTcmclc9/hN7piE62sC4UgHPtXFdShvnaub44EdELUyvu+YKsbWxHzIfQAjaKh553TIuVnpBmm+TDNAGQ==`。

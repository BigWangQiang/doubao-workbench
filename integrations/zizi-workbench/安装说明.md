# Lalor 工作台插件安装说明

本包版本 2.1.1，配合 Lalor 工作台 3.0.1 使用。连接按本机接口协议发现，不锁定工作台应用版本号；支持工作台自定义数据目录。先在工作台完成有效会员登录，再在插件内刷新账号池。

旧插件无需降级到 2.6.0。先更新工作台到 3.0.1，即可恢复本机连接；推荐同时更新本插件，以消除旧提示并识别自定义目录。仅刷新账号/模型不会创建生成任务。

## 包含内容

- `image_plugin_lalor_workbench`：图片生成插件，调用 Lalor 工作台的豆包/Dola 图片账号池。
- `video_plugin_lalor_workbench`：视频生成插件，调用 Lalor 工作台的视频账号池，并支持参考图、参考视频、参考音频。

## 安装方法（推荐）

1. 完全退出字字动画。
2. 打开本压缩包，进入里面的 `user_resources` 文件夹。
3. 将这个 `user_resources` 文件夹复制到“字字动画安装根目录”，出现同名文件夹时选择“合并”。
4. 重新启动字字动画。
5. 在图片模型/视频模型的插件列表中确认出现：
   - `Lalor 工作台图片插件`
   - `Lalor 工作台视频插件`
6. 打开插件设置，选择“豆包”或“Dola”账号池，再点击“刷新账号/刷新模型”。

### 正确的最终路径

假设字字动画安装目录是：

```text
C:\Users\Administrator\Desktop\字字动画_9_0_9
```

复制合并后应当看到：

```text
C:\Users\Administrator\Desktop\字字动画_9_0_9\user_resources\plugins\image_plugins\image_plugin_lalor_workbench\main.py
C:\Users\Administrator\Desktop\字字动画_9_0_9\user_resources\plugins\image_plugins\image_plugin_lalor_workbench\info.json
C:\Users\Administrator\Desktop\字字动画_9_0_9\user_resources\plugins\image_plugins\image_plugin_lalor_workbench\ui\index.html

C:\Users\Administrator\Desktop\字字动画_9_0_9\user_resources\plugins\video_plugins\video_plugin_lalor_workbench\main.py
C:\Users\Administrator\Desktop\字字动画_9_0_9\user_resources\plugins\video_plugins\video_plugin_lalor_workbench\info.json
C:\Users\Administrator\Desktop\字字动画_9_0_9\user_resources\plugins\video_plugins\video_plugin_lalor_workbench\ui\index.html
```

## 最省事的复制方式

把压缩包解压后，直接把里面的 `user_resources` 文件夹拖到字字动画安装目录的最外层：

```text
字字动画_9_0_9\
├─ _internal\
├─ resources\
├─ user_resources\  ← 把压缩包里的同名文件夹合并到这里
└─ ...
```

## 不要放错位置

- 不要把插件放到 `_internal\plugins`。
- 不要只复制 `main.py`；`info.json` 和 `ui\index.html` 也要一起复制。
- 不要复制或分享已有的 `config.json`，它可能包含本机插件设置；安装后在插件设置页重新选择账号池即可。
- 账号、Token、Cookie 不在此包内，插件只通过本机 Lalor 工作台的 loopback 接口通信。

## 升级旧版本

关闭字字动画后，用本包的 `user_resources\plugins\image_plugins\image_plugin_lalor_workbench` 和 `video_plugins\video_plugin_lalor_workbench` 覆盖旧的同名插件目录，然后重新启动。旧目录建议先改名备份，不要删除。

## 验收

先在插件设置页确认能读取到账号池；再用一张参考图测试图片生成，用一张参考图测试视频生成。只有把图片放进当前任务的“参考项”后，才会作为参考图随任务提交。

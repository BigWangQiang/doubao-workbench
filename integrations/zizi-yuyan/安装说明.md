# 屿砚 AI 视频插件（字字动画）

1. 完全退出字字动画，把本 ZIP 的 `user_resources` 文件夹合并到字字动画安装根目录。新版插件会与「Lalor 工作台视频插件」并存。
2. 登录 [屿砚 AI](https://yuyan-ai.site/connections/desktop)，创建一个专供字字动画使用的客户 API Key。在字字动画的「视频模型管理 → 自定义插件」选择「屿砚 AI 视频插件」，填入 Key，点「读取网站模型」。Key 保存在字字动画本机插件配置中，不要分享该配置文件；可在网站撤销 Key。
3. 选择网站实际开放给该账号的模型、时长、画幅和清晰度。读取模型不会提交生成，也不会扣费。会员模型仍需账号具备对应权限；点击分镜「生成视频」才按网站规则提交和计费。
4. 点击分镜「生成视频」后，插件把该分镜的提示词及选中的本地参考素材发送给屿砚 AI。在同一账号的 [视频生成 → 作品](https://yuyan-ai.site/toolbox/video) 可刷到此任务；完成后，字字动画会把成片放回原分镜。不需要保持浏览器或屿砚工作台开着，但自动回填需要字字动画保持运行直到任务完成。已经单独在网页点击生成的其他任务不会回填。
5. 分镜进度条会定期读取网站百分比，并区分「排队」「生成」「回传」。限流或短时断线时会继续查询，插件单次最多等 120 分钟。若字字动画提前报错或关闭，打开原项目，保持该分镜提示词不变，再点「生成视频／重新生成」会续查该分镜已保存的原任务；不会重新提交或扣费。升级前 v1.0.0 发的任务没有本地续传记录，请直接从网站「视频生成 → 作品」下载。

## 插件与网站的约定

- 字字动画插件宿主提供 `generate(context)`，输入包括分镜的 `viewer_index` 和 `prompt`、可选 `plugin_params`、可选进度回调、可选首尾帧以及参考素材；输出为 `list[str]` 本地视频路径，由当前调用的原分镜接收。保存目录取宿主的 `project_path` 或 `output_dir`；缺少分镜编号、目录或提示词时阻止提交。
- 网站客户 API 通过 HTTPS + Bearer Key 访问，承诺 JSON 信封、模型能力和文件 ID。Key 只发送到 `https://yuyan-ai.site/api/v1`；成片接口如返回 HTTPS 对象存储下载地址，使用不带 Key 的新请求访问，拒绝后续跳转。可选参数由模型目录约束；参考文件先上传，再提交 `surface=video-workbench` 的异步视频任务。插件只接受该任务自己的视频文件接口地址，完整下载且验证文件长度后才回填。
- 插件不会猜测模型：目录为不可用、要求额外会员权限的模型以及纯视频处理模型不可选；生成前再查已选模型和规格。模型变更后需重新选；网站端对不支持的素材、计费和余额做最终判断。
- 进度与恢复：生成时使用网站任务的 `status` 和 `progress`，活动百分比与作品页一致。`GET` 查询遇到网络错误、429 或网关／服务暂不可用，按照 `Retry-After` 或退避继续；下载中断或不足字节时仅重新读取该任务成片。窗口退出时保留任务。插件在项目的 `.yuyan-video-tasks` 中按分镜和输出位置及提示词摘要登记请求和原任务编号，并使用本机文件锁保护同一分镜，记录不含 Key 或提示词原文。提交结果不明且尚未取得任务编号时保留记录并阻止再次提交，需先到网站核对。明确拒绝的请求或网站明确失败／取消的任务允许重新生成。
